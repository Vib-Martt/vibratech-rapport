Vibratech v18.6

Remplacez les fichiers du site GitHub par le contenu de cette archive (pas le ZIP lui-même). Gardez index.html à la racine.

Client : saisie libre acceptée. Cliquez sur « Utiliser ce nom » pour confirmer un nouveau nom. Les suggestions restent facultatives.

iPhone : « Partager / imprimer le PDF » ouvre le partage du PDF lorsque disponible. Choisissez Imprimer, ou enregistrez dans Fichiers puis Partager > Imprimer.

Les rapports restent locaux à chaque appareil : cette version ne configure pas de synchronisation automatique.
