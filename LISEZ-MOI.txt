VIBRATECH 19.13 — QUANTITÉS ET SIGNATURE

Matériel : les quantités acceptent uniquement les chiffres et un séparateur décimal (virgule ou point), avec un clavier décimal sur mobile. Les données des anciens rapports restent conservées au chargement.
PDF : le nom du signataire, la date et le cadre de signature sont regroupés vers la marge droite. Le même résultat apparaît dans l’aperçu avant signature.

INSTALLATION
Conserver la version précédente. Remplacer le contenu de l’application sur GitHub par les fichiers de cette version, y compris js/ et css/.
Rouvrir/recharger l’application sur chaque appareil et vérifier v19.13 dans Synchronisation. Ne pas effacer les données du navigateur.
Cette copie n’a pas été publiée par l’assistant.
CORRECTION — PHOTOS ET BOUTON PDF
Le bouton d’aperçu avant signature est jaune.
Les photos des rapports enregistrés sont désormais envoyées avec le rapport et récupérées dans le stockage photo de chaque navigateur.
Installer cette version sur tous les appareils. Sur l’appareil contenant les photos originales, enregistrer le rapport dans l’historique, puis lancer Synchroniser. Synchroniser ensuite l’autre appareil et ouvrir le rapport depuis l’historique.
Les brouillons seuls ne sont pas synchronisés. Ne pas effacer les données du navigateur d’origine : elles sont nécessaires pour récupérer les anciennes photos.
Les photos peuvent augmenter le temps et le volume des transferts. Si un transfert échoue, le statut signale que la synchronisation est non terminée ; réessayer avec une connexion stable.
Validation : tests locaux avec serveur simulé ; connexion au compte réel et déploiement non effectués.

IMPRESSION UNIFIÉE
Sur ordinateur, « Imprimer le PDF » ouvre le même PDF que le téléchargement de fin de rapport, dans un nouvel onglet. Utiliser le bouton Imprimer du lecteur PDF. Si l’ouverture est bloquée, le PDF est téléchargé pour être ouvert et imprimé.
Sur iPhone/iPad, utiliser Imprimer dans le menu de partage du PDF.
L’impression ne termine pas le rapport et ne le sauvegarde pas dans l’historique.

MISE À JOUR SAFARI — IMPRESSION
Les scripts et la feuille de style portent maintenant une adresse de mise à jour pour éviter de réutiliser les anciens fichiers en cache.
Après remplacement des fichiers sur GitHub, ouvrir https://vib-martt.github.io/vibratech-rapport/?maj=impression-6 avec Internet.
Le bouton doit afficher « Ouvrir le PDF pour imprimer » sur Mac. Il ouvre le PDF actuel, dont la signature est à droite, dans un nouvel onglet.
Aucune suppression des données du navigateur n’est nécessaire.

SIGNATURE DES ANCIENS RAPPORTS
L’image de signature enregistrée est désormais conservée indépendamment du cadre de dessin. L’ouverture d’un ancien rapport et l’impression immédiate ne nécessitent plus d’afficher l’onglet Signer.
La correction préserve une signature présente dans les données du rapport ; elle ne recrée pas une signature déjà remplacée par une image vide dans une sauvegarde antérieure.
Après transfert sur GitHub, ouvrir https://vib-martt.github.io/vibratech-rapport/?maj=signature-7 puis ouvrir un rapport signé depuis l’historique et utiliser « Ouvrir le PDF pour imprimer ».
Validation : 8 tests locaux de signature et 5 tests d’impression réussis. Vérification sur les appareils réels à effectuer après installation.
